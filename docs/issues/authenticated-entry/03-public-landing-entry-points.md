# 03: Provide the public landing page entry points

**Blocked by:** 01, 02
**Type:** AFK

## What
Replace the starter home page with Quizz Arena's public landing page. It provides a black-screen entry experience and clear navigation to the completed Login and Sign up routes.

## Acceptance criteria

- [ ] `/` is publicly accessible without an authenticated session.
- [ ] The page uses a black screen presentation and a prominent heading.
- [ ] The page presents clear Login and Sign up actions.
- [ ] The Login action navigates to `/login` and the Sign up action navigates to `/signup`.
- [ ] The page follows the existing project fonts, spacing, and color foundations.
