# Quizz Arena

SvelteKit quiz app for signing in and playing quizzes.

## Rules

Keep code clean, simple, typed, accessible, and component-focused. Follow existing SvelteKit/Tailwind patterns.
Follow project conventions in `docs/CONVENTIONS.md`.
Use design tokens defined in `src/app.css`.

## Run

`npm install` · `npm run dev` · `npm run check` · `npm run lint` · `npm run build`
